# お知らせAPI設計書

## 1. 概要

作業員向けのお知らせ情報を取得するためのAPI。

## 2. エンドポイント

### GET /api/notifications

お知らせの一覧を取得する。

#### 2.1. リクエスト

なし

#### 2.2. レスポンス

ステータスコード: 200 OK

レスポンスボディ:

```json
[
  {
    "id": "1",
    "title": "【重要】台風接近に伴う作業中止の判断について",
    "summary": "台風接近に伴う対応について",
    "content": "本日の午後以降の検針作業は、天候の状況により各自の判断で中止してください。安全第一で行動し、無理な作業は控えるようお願いします。詳細は添付のPDFをご確認ください。",
    "publishedAt": "2024-07-26T10:00:00+09:00",
    "category": "IMPORTANT",
    "isRead": false
  },
  {
    "id": "2",
    "title": "新システム移行に伴うマニュアル公開",
    "summary": "新システムマニュアルについて",
    "content": "来月からの新メーター導入に伴い、ハンディターミナルの操作手順書が更新されました。各自ダウンロードの上、内容を確認してください。",
    "publishedAt": "2024-07-25T15:00:00+09:00",
    "category": "INFO",
    "isRead": true
  }
]
```

#### 2.3. レスポンスフィールド

| フィールド名       | 型      | 説明                               | 必須 |
| ------------------ | ------- | ---------------------------------- | ---- |
| id                 | String  | お知らせID                         | ○    |
| title              | String  | タイトル                           | ○    |
| summary            | String  | 概要                               | ○    |
| content            | String  | 本文                               | ○    |
| publishedAt        | String  | 掲載開始日時 (ISO 8601形式等)        | ○    |
| category           | String  | カテゴリ (例: IMPORTANT, INFO, ADMIN) | ○    |
| isRead             | boolean | 既読フラグ                         | ○    |
