# テーブル定義書

## 1. 概要
本ドキュメントは、gasworksシステムにおけるデータベースの物理設計を定義します。作業員用UIプロトタイプの要件に基づき、検針業務、通知管理、および位置情報をカバーしています。

---

## 2. users (利用者)
システムを利用する作業員および管理者を管理します。

| カラム名 | データ型 | NULL | Key | 説明 |
|:---|:---|:---:|:---:|:---|
| `id` | BIGINT | N | PK | 主キー |
| `name` | VARCHAR(255) | N | | 氏名 |
| `email` | VARCHAR(255) | N | UK | メールアドレス（ログインID） |
| `password` | VARCHAR(255) | N | | ハッシュ化されたパスワード |
| `role` | VARCHAR(50) | N | | 権限（'ADMIN', 'WORKER'） |
| `created_at` | TIMESTAMP | N | | 作成日時 |
| `updated_at` | TIMESTAMP | N | | 更新日時 |

---

## 3. customers (顧客)
ガス利用者の基本情報。ルートマップ表示のために座標情報を保持します。

| カラム名 | データ型 | NULL | Key | 説明 |
|:---|:---|:---:|:---:|:---|
| `id` | BIGINT | N | PK | 主キー |
| `name` | VARCHAR(255) | N | | 顧客名 |
| `address` | VARCHAR(255) | N | | 住所 |
| `contact` | VARCHAR(50) | N | | 連絡先電話番号 |
| `latitude` | DECIMAL(9, 6) | Y | | 緯度（マップ表示用） |
| `longitude` | DECIMAL(9, 6) | Y | | 経度（マップ表示用） |
| `created_at` | TIMESTAMP | N | | 作成日時 |

---

## 4. assignments (作業割当)
「担当顧客一覧」画面の基となるデータ。誰が・いつ・どの顧客を検針するかを定義します。

| カラム名 | データ型 | NULL | Key | 説明 |
|:---|:---|:---:|:---:|:---|
| `id` | BIGINT | N | PK | 主キー |
| `user_id` | BIGINT | N | FK | 担当作業員ID |
| `customer_id` | BIGINT | N | FK | 対象顧客ID |
| `scheduled_date` | DATE | N | | 予定日 |
| `status` | VARCHAR(20) | N | | 状態（'PENDING', 'COMPLETED', 'SKIPPED'） |

---

## 5. meter_readings (検針データ)
検針結果。プロトタイプにある「メーター写真」のパスを保持します。

| カラム名 | データ型 | NULL | Key | 説明 |
|:---|:---|:---:|:---:|:---|
| `id` | BIGINT | N | PK | 主キー |
| `assignment_id` | BIGINT | N | FK | 作業割当ID |
| `value` | DECIMAL(10, 2) | N | | 検針値 |
| `image_path` | VARCHAR(500) | Y | | メーター写真のファイルパス/URL |
| `reading_at` | TIMESTAMP | N | | 検針日時 |
| `created_at` | TIMESTAMP | N | | 登録日時 |

---

## 6. notifications (お知らせ)
本部から作業員へ発信される通知。プロトタイプの「重要度」を反映します。

| カラム名 | データ型 | NULL | Key | 説明 |
|:---|:---|:---:|:---:|:---|
| `id` | BIGINT | N | PK | 主キー |
| `title` | VARCHAR(255) | N | | タイトル |
| `summary` | TEXT | Y | | 一覧用概要 |
| `content` | TEXT | N | | 本文 |
| `category` | VARCHAR(20) | N | | 重要度（'ALERT', 'WARN', 'INFO'） |
| `published_at` | TIMESTAMP | N | | 公開日時 |

---

## 7. user_notifications (通知既読管理)
作業員ごとの既読・未読状態を管理します。

| カラム名 | データ型 | NULL | Key | 説明 |
|:---|:---|:---:|:---:|:---|
| `user_id` | BIGINT | N | PK, FK | 作業員ID |
| `notification_id` | BIGINT | N | PK, FK | 通知ID |
| `is_read` | BOOLEAN | N | | 既読フラグ（default: false） |
| `read_at` | TIMESTAMP | Y | | 既読日時 |
