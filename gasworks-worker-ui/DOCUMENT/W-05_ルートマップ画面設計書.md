# W-05: ルートマップ画面設計書

## 1. 概要
本日の検針対象顧客の位置を地図上にプロットし、効率的な巡回ルートを視覚的に提示する画面です。
現在地からの距離感や、次に訪問すべき顧客の場所を作業員が直感的に把握することを目的とします。

## 2. 画面レイアウト案

- **ヘッダー**: `layout/base.html` を継承（「ルートマップ」のタイトルを表示）
- **マップエリア**: 全画面表示に近いサイズで地図を描画（Google Maps 等）
- **情報オーバーレイ（下部）**: 選択された顧客の氏名、住所、および検針ステータスを簡潔に表示
- **操作ボタン**:
  - 地図上のピン：タップで顧客情報を表示
  - 顧客情報内のボタン：検針データ入力画面（W-04）へ遷移
  - 戻るボタン：業務メニュー画面（W-02）へ遷移

## 3. 画面項目定義

| 項目ID | 項目名 | 表示形式 | 説明 | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| L-01 | マップ | コンポーネント | 道路、建物、現在地を表示 | 地図ライブラリを利用 |
| L-02 | 顧客ピン | アイコン | 顧客の所在地をプロット。未/済で色分け | 未：赤、済：青など |
| L-03 | 巡回ルート | ライン | 割当順に基づいた推奨巡回経路を表示 | 直線または道路沿い |
| L-04 | 顧客詳細（小）| パネル | ピン選択時に表示される顧客情報の概要 | 名前・住所・距離など |
| B-01 | 検針を開始 | ボタン | 選択中の顧客の検針データ入力（W-04）へ遷移 | |
| B-02 | 戻る | リンク | 業務メニュー画面（W-02）へ戻る | |

## 4. 機能詳細

### 4.1. 地図データの描画
- `GET /api/assignments` から取得した顧客の緯度 (`latitude`)・経度 (`longitude`) を地図上にプロットする。
- ブラウザの Geolocation API を使用して作業員の現在地を取得し、地図上の中央またはアイコンで表示する。

### 4.2. ピンの選択と連携
- ピンをタップすると、画面下部にその顧客の概要が表示される。
- すでに検針済みの顧客については、ピンの色を変更し、重複訪問を防止する。

### 4.3. 画面遷移
- 顧客詳細パネル内の「検針を開始」ボタンを押下すると、その `assignmentId` を保持して W-04 画面へ遷移する。

## 5. 連携API

### GET /api/assignments
詳細は `gasworks-api\DOCUMENT\API仕様書.md` を参照。

#### レスポンスデータ利用項目
- `customer.latitude` / `customer.longitude`: プロット位置
- `customer.name`: 表示名
- `status`: ピンの色の判別

## 6. UI/UX上の配慮
- **視認性**: ピンの間隔が近い場合は、地図のズームレベルを調整して重なりを防ぐ。
- **使い勝手**: 現場で手袋をはめていても操作しやすいよう、ピンのタップ判定領域は広めに確保する。

## 7. 注意事項
- インメモリDBのため、再起動後は顧客の配置（割当データ）が変わる可能性がある。
- オフライン時は地図タイルが読み込めないため、キャッシュ機能の検討またはオフライン警告を表示する。
