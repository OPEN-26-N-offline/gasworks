# W-04: 検針データ入力画面設計書

## 1. 概要
現場でガスメーターの数値を読み取り、証跡となる写真とともにサーバーへ登録するための画面です。
誤入力を防ぐための視認性と、カメラ機能とのスムーズな連携を重視した設計とします。

## 2. 画面レイアウト案

- **ヘッダー**: `layout/base.html` を継承（「検針データ入力」のタイトルを表示）
- **顧客情報エリア**: 顧客名、住所を大きく表示（誤った場所での入力を防止）
- **検針値入力エリア**: 数値キーボードが標準で表示される入力フィールド
- **写真撮影・添付エリア**: メーター写真のプレビュー表示と、カメラ起動/ファイル選択ボタン
- **操作ボタンエリア**: 画面最下部に固定された「登録する」ボタン（青色）と「戻る」ボタン

## 3. 画面項目定義

| 項目ID | 項目名 | 表示形式 | 説明 | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| L-01 | 顧客名 | テキスト | 対象顧客の氏名を表示 | |
| L-02 | 住所 | テキスト | 対象顧客の住所を表示 | |
| I-01 | 検針値 | 数値入力 | 現在のメーター数値を入力 | 小数点対応 (`input type="number"`) |
| I-02 | メーター写真 | ファイル | メーターの指針を撮影した画像 | プレビュー表示を伴う |
| B-01 | 登録する | ボタン | 入力内容をAPIへ送信し、検針を完了する | 送信中は非活性化 |
| B-02 | 戻る | リンク | 担当顧客一覧画面（W-03）へ戻る | |

## 4. 機能詳細

### 4.1. 詳細情報の表示
- 画面遷移時に受け取った `assignmentId` をキーに `GET /api/assignments/{id}` を呼び出し、対象顧客の正確な情報を表示する。

### 4.2. 写真撮影・プレビュー
- スマートフォンのカメラ機能を呼び出し、撮影した画像を画面上で確認できるようにする。
- 画像サイズが大きい場合は、送信前にフロントエンド側でリサイズを行うことを推奨。

### 4.3. データ登録処理
- 「登録する」ボタン押下時、`POST /api/meter-readings` を実行する。
- 登録成功後、API側で `assignments.status` が `COMPLETED` に更新されることを前提とし、自動的に担当顧客一覧画面（W-03）へ遷移する。

## 5. 連携API

### GET /api/assignments/{id}
作業割当の詳細（顧客情報含む）を取得します。

### POST /api/meter-readings
詳細は `gasworks-api\DOCUMENT\API仕様書.md` を参照。

#### リクエストデータ例 (JSON)
```json
{
  "assignmentId": 501,
  "value": 1234.5,
  "imagePath": "/storage/meter/photo_501.jpg"
}
```

## 6. UI/UX上の配慮
- **入力負荷の軽減**: 検針値入力フィールドにフォーカスした際、スマートフォン側で自動的に数値キーボードが開くように設定。
- **誤認防止**: 顧客名を強調表示し、訪問先と入力対象に間違いがないか作業員に注意を促す。

## 7. 注意事項
- インメモリDBを使用しているため、サーバー再起動後は登録した検針データも消去される。
