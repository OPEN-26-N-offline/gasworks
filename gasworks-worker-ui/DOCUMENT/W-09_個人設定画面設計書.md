# W-09: 個人設定画面設計書

## 1. 概要
作業員自身のプロフィール情報の確認、およびアプリケーションの動作設定（表示モードや通知設定）を行うための画面です。
個々の作業環境に合わせた最適化を行い、利便性を向上させることを目的とします。

## 2. 画面レイアウト案

- **ヘッダー**: `layout/base.html` を継承（「個人設定」のタイトルを表示）
- **プロフィールエリア**:
  - ユーザー名、メールアドレス、所属、作業員番号の表示（基本は読み取り専用）
- **アプリ設定エリア**:
  - 表示モード切替（ライト / ダーク / システム連動）
  - プッシュ通知のON/OFF（検針漏れ防止アラート等）
- **操作ボタンエリア**:
  - 「設定を保存」ボタン
  - 業務メニュー（W-02）へ戻るリンク

## 3. 画面項目定義

| 項目ID | 項目名 | 表示形式 | 説明 | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| L-01 | 作業員氏名 | テキスト | ログインユーザーの氏名を表示 | |
| L-02 | 作業員番号 | テキスト | 社内システムと紐づくIDを表示 | |
| S-01 | 表示モード | セレクト | ライト、ダーク、システム設定から選択 | ローカル保存 |
| S-02 | 通知設定 | スイッチ | アプリからの通知の有効/無効を切り替え | |
| B-01 | 設定を保存 | ボタン | 変更した設定をアプリ（またはサーバー）に保存 | |
| B-02 | 戻る | リンク | 業務メニュー画面（W-02）へ戻る | |

## 4. 機能詳細

### 4.1. ユーザー情報の表示
- 認証トークン（JWT）に含まれる情報、または将来的な `/api/auth/me` APIを用いて情報を取得・表示する。

### 4.2. 表示モードの変更
- 選択されたモードに基づき、CSS変数を切り替える。
- 設定値はブラウザの `localStorage` に保存し、次回起動時にも反映されるようにする。

### 4.3. 設定の保存
- 「設定を保存」ボタン押下時、変更内容を確定させる。
- 完了後、トースト通知で保存完了を通知する。

## 5. 連携API

### なし (フェーズ1)
- プロフィール情報はログイン時のセッション情報を使用。
- 表示設定はフロントエンド（LocalStorage）で完結。

### 将来的な拡張
- `GET /api/auth/me`: 詳細なプロフィール情報の取得
- `PATCH /api/users/settings`: サーバー側でのユーザー設定の永続化

## 6. UI/UX上の配慮
- **読みやすさ**: ユーザー情報は文字を大きく表示し、確認しやすくする。
- **設定の直感性**: スイッチやセレクトボックスは、モバイル端末の標準的なUI部品を使用し、操作ミスを防ぐ。

## 7. 注意事項
- インメモリDB環境であっても、表示モードなどのローカル設定は `localStorage` を使用するため、ブラウザを閉じても維持される設計とする。
