# W-07: 日報作成・同期画面設計書

## 1. 概要
1日の検針作業の実績を振り返り、報告内容に漏れがないかを確認した上で、サーバーへ最終同期（業務終了報告）を行うための画面です。
作業員は本日の進捗率を視覚的に確認し、安心して業務を終了できることを目的とします。

## 2. 画面レイアウト案

- **ヘッダー**: `layout/base.html` を継承（「日報作成・同期」のタイトルを表示）
- **進捗サマリーエリア**: 円グラフやプログレスバーを用いた進捗率の視覚表示
- **実績内訳エリア**: 予定数、完了数、スキップ（中断）数、未着手数をカード形式で表示
- **同期・終了ボタン**: 画面最下部に配置される大きな実行ボタン

## 3. 画面項目定義

| 項目ID | 項目名 | 表示形式 | 説明 | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| L-01 | 本日の進捗率 | グラフ/テキスト | 完了数 / 全体数 をパーセンテージで表示 | 100%時は色を強調 |
| L-02 | 作業予定数 | 数値 | 本日の全割当件数 | |
| L-03 | 完了件数 | 数値 | 検針データ登録が完了した件数 | |
| L-04 | 中断/スキップ数 | 数値 | 何らかの理由でスキップされた件数 | |
| B-01 | 最終同期を実行 | ボタン | サーバーへ最終ステータスを送信し業務を終了 | 完了後はメニューへ戻る |
| B-02 | 戻る | リンク | 業務メニュー画面（W-02）へ戻る | |

## 4. 機能詳細

### 4.1. 実績データの取得
- 画面ロード時に `GET /api/assignments/summary` を呼び出し、最新の統計情報を取得して画面に反映する。

### 4.2. 未完了作業の警告
- 未完了の作業（PENDING）が残っている状態で「最終同期を実行」を押下した場合、確認ダイアログ（「未完了の作業がありますが、終了してよろしいですか？」）を表示する。

### 4.3. 同期完了処理
- 同期実行後、成功メッセージを表示し、作業員の端末側に残っている一時キャッシュ（もしあれば）をクリアして業務メニューへ遷移する。

## 5. 連携API

### GET /api/assignments/summary
詳細は `gasworks-api\DOCUMENT\API仕様書.md` を参照。

#### レスポンスデータ例 (JSON)
```json
{
  "totalCount": 20,
  "completedCount": 18,
  "skippedCount": 1
}
```

## 6. UI/UX上の配慮
- **達成感の演出**: 全件完了（100%）時には、お祝いのアイコンやメッセージを表示し、作業員のモチベーションを維持する。
- **一目でわかる進捗**: テキストだけでなく、プログレスバーなどの色（緑：完了、赤：未完了など）を用いて、直感的に状況を把握できるようにする。

## 7. 注意事項
- インメモリDB環境では、サーバー再起動により当日の実績もリセットされるため、デモの際は再起動前に確認を行うこと。
- ネットワーク不安定な環境を考慮し、同期中はローディングアニメーションを表示し、二重送信を防止する。
