# HP向け画面仕様書

## 1. 概要

本仕様書は、作業員が利用するフロントエンドアプリケーション（gasworks-hp-ui）の画面仕様を定義します。

## 2. 画面一覧

- **ログイン画面**: 最初に表示される画面。
- **担当顧客一覧画面**: ログイン後に表示される、自分が担当する顧客の一覧。
- **検針データ入力画面**: 顧客を選択し、検針値を入力・登録する画面。
- **マイページ画面**: 自身の情報を確認・変更する画面。

## 4. 各画面の詳細

### 4.1. ログイン画面
- **機能**: メールアドレスとパスワードを入力してログインする。
- **レイアウト**:
  - メールアドレス入力欄
  - パスワード入力欄
  - ログインボタン

### 4.2. 担当顧客一覧画面
- **機能**: 担当する顧客を一覧で表示する。顧客名や住所で検索できる。
- **レイアウト**:
  - 検索ボックス
  - 顧客リスト（顧客名、住所）
  - 各顧客への「検針入力」ボタン

### 4.3. 検針データ入力画面
- **機能**: 検針値を入力し、写真を添付して登録する。
- **レイアウト**:
  - 顧客情報（名前、住所）
  - 検針日入力欄（デフォルトは当日）
  - 検針値入力欄
  - メーターの写真アップロード機能
  - 登録ボタン
