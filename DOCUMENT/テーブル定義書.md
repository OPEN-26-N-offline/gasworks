# テーブル定義書

## 1. 概要

本ドキュメントは、データベースの各テーブルのスキーマ（カラム、データ型、制約など）を詳細に定義します。

---

## 2. users

- **テーブル名**: `users`
- **説明**: システムの利用者（管理者、作業員）を管理する。

| カラム名 | データ型 | NULL | Key | 説明 |
|:---|:---|:---:|:---:|:---|
| `id` | BIGINT | N | PK | 主キー |
| `name` | VARCHAR(255) | N | | 氏名 |
| `email` | VARCHAR(255) | N | UK | メールアドレス（ログインID） |
| `password` | VARCHAR(255) | N | | ハッシュ化されたパスワード |
| `role` | VARCHAR(50) | N | | 権限（'ADMIN' or 'WORKER'） |
| `created_at` | TIMESTAMP | N | | 作成日時 |
| `updated_at` | TIMESTAMP | N | | 更新日時 |

---

## 3. customers

- **テーブル名**: `customers`
- **説明**: ガスを利用する顧客情報を管理する。

| カラム名 | データ型 | NULL | Key | 説明 |
|:---|:---|:---:|:---:|:---|
| `id` | BIGINT | N | PK | 主キー |
| `name` | VARCHAR(255) | N | | 顧客名 |
| `address` | VARCHAR(255) | N | | 住所 |
| `contact` | VARCHAR(50) | N | | 連絡先 |
| `created_at` | TIMESTAMP | N | | 作成日時 |
| `updated_at` | TIMESTAMP | N | | 更新日時 |

---

## 4. meter_readings

- **テーブル名**: `meter_readings`
- **説明**: 作業員が記録した検針データを管理する。

| カラム名 | データ型 | NULL | Key | 説明 |
|:---|:---|:---:|:---:|:---|
| `id` | BIGINT | N | PK | 主キー |
| `customer_id` | BIGINT | N | FK | 顧客ID (customers.id) |
| `user_id` | BIGINT | N | FK | 作業員ID (users.id) |
| `reading_date` | DATE | N | | 検針日 |
| `value` | DECIMAL(10, 2) | N | | 検針値 |
| `created_at` | TIMESTAMP | N | | 作成日時 |
| `updated_at` | TIMESTAMP | N | | 更新日時 |
