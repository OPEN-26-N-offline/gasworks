# 管理者向け画面仕様書

## 1. 概要

本仕様書は、管理者が利用するDjango管理画面の仕様を定義します。
Djangoの標準的な管理機能（django.contrib.admin）を最大限に活用し、迅速な開発を目指します。

## 2. 管理対象モデル

Django管理サイトでは、以下のデータベースモデル（テーブル）を管理できるようにします。

- **Users（利用者）**:
  - 作業員や管理者のアカウントを作成・更新・削除する。
  - パスワードリセット機能を提供する。
  - ロール（権限）の変更を行う。

- **Customers（顧客）**:
  - 顧客情報のCRUD（作成、読み取り、更新、削除）操作を行う。
  - CSVファイルからの顧客情報一括インポート・エクスポート機能を提供する。

- **MeterReadings（検針データ）**:
  - 全ての検針データを一覧で確認する。
  - 日付、作業員、顧客などでデータをフィルタリング・検索する。
  - 不正なデータの修正や削除を行う。

## 3. カスタマイズ

- **一覧画面の表示項目**: 各モデルの一覧画面で、重要な情報（例: 顧客名、最終検針日など）が一覧で確認できるように表示項目をカスタマイズします。
- **検索・フィルタ機能**: `list_filter` や `search_fields` を設定し、管理者が必要なデータを効率的に探せるようにします。
- **カスタムアクション**: 特定の条件でデータを一括更新するようなカスタムアクションを追加します。（例: 選択したユーザーを無効化する）

## 4. 画面構成（例: Django Admin）

Djangoの標準機能を利用するため、詳細な画面レイアウト設計は省略します。
以下は、Django Adminが自動生成する画面のイメージです。

- **ログイン画面**
- **ダッシュボード（App一覧）**
  - `Users`
  - `Customers`
  - `MeterReadings`
- **モデルごとの一覧画面（Change List）**
- **モデルごとの編集画面（Change Form）**
