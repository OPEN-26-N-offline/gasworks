# 仕様書一覧

- [ ] [全体構成図](全体構成図.md) - システム全体のアーキテクチャ、技術スタック、各コンポーネントの連携を記述します。

## 2. API仕様

- [ ] [バッチ処理仕様書](バッチ処理仕様書.md) - 定期実行するバッチの処理内容、実行タイミング、エラーハンドリングなどを定義します。
