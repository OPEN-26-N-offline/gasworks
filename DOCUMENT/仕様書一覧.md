# 仕様書一覧

このドキュメントは、giveryプロジェクトで作成する仕様書の一覧を管理するものです。

## 1. 全体設計

- [ ] [全体構成図](全体構成図.md) - システム全体のアーキテクチャ、技術スタック、各コンポーネントの連携を記述します。

## 2. API仕様

- [ ] [API仕様書](../gasworks-api/DOCUMENT/API仕様書.md) - Spring Bootで実装するRESTful APIのエンドポイント、リクエスト/レスポンス形式、認証方法などを定義します。

## 3. データベース設計

- [ ] [ER図](../gasworks-api/DOCUMENT/ER図.puml) - MySQLデータベースのテーブル構造、リレーションシップを定義します。
- [ ] [テーブル定義書](../gasworks-api/DOCUMENT/テーブル定義書.md) - 各テーブルのカラム、データ型、制約などを詳細に記述します。

## 4. 画面仕様

- [ ] [ホームページ画面仕様書](../gasworks-hp-ui/DOCUMENT/ホームページ画面仕様書.md) - gasworks-hp-uiで作成する一般向けサイトの仕様を定義します。
- [ ] [作業員向け画面仕様書](../gasworks-worker-ui/DOCUMENT/作業員向け画面仕様書.md) - gasworks-worker-uiで作成する作業員用モバイルUIの仕様を定義します。
    - [ ] [UIプロトタイプ](../gasworks-worker-ui/prototype/) - 画面設計のベースとなるHTMLプロトタイプ一式です。
- [ ] [管理者向け画面仕様書](../gasworks-admin/DOCUMENT/管理者向け画面仕様書.md) - Djangoで作成する管理画面のレイアウト、機能、画面遷移を定義します。

## 5. バッチ処理仕様

- [ ] [バッチ処理仕様書](../gasworks-batch/DOCUMENT/バッチ処理仕様書.md) - 定期実行するバッチの処理内容、実行タイミング、エラーハンドリングなどを定義します。
